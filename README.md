# ClickFunnels 2.0 Sales Funnel Interactive Prototype
### **Strata 2.0 — High-Converting Sales Architecture & Client Acquisition Engine**

A modern, fully responsive, self-contained interactive sales funnel prototype built with **pure HTML, CSS, and vanilla JavaScript**. Engineered according to **ClickFunnels 2.0** architecture principles to demonstrate end-to-end buyer journeys for high-ticket digital products, masterminds, and agency offerings.

---

## 🚀 Live Demo & Presentation Features

- **Zero Dependencies**: 100% vanilla HTML5, CSS3, and modern JavaScript. Runs offline and directly in any browser by double-clicking `index.html`.
- **Ultra-Responsive**: Fully optimized for Desktop, Tablet, and Mobile screens (down to 320px width).
- **Mobile-First Stepper**: Sticky bottom bar on mobile (`‹ Prev | STEP X OF 8 | Next ›`) allowing prospective clients to navigate the entire funnel with a single thumb.
- **5-Minute Guided Client Tour**: Interactive walkthrough modal highlighting conversion psychology, tracking setup, and platform requirements.
- **Persistent Prototype Status**: Clear visual distinctions between simulated demo interactions and live ClickFunnels 2.0 configurations.

## 📋 The 8 Interactive Funnel Stages

| # | Section | Overview & Interactive Mechanics |
|---|---|---|
| **1** | **Sales Page** | High-ticket headline, trust metrics, **interactive Vimeo-style video player modal** (play/pause/timeline scrubbing), curriculum breakdown with 3D product showcase, social proof case studies, and instant access CTAs. |
| **2** | **Checkout Page** | **Dual Order Bumps:**<br>• *Bump 1 (VIP Toolkit: +$47)*: Instantly updates order total to $244.<br>• *Bump 2 (Hardcover Playbook: +$29)*: **Dynamically reveals physical shipping address fields** and updates total to $273.<br>• Full inline validation and 256-bit SSL encryption badge. |
| **3** | **One-Click Upsell** | **$297/month Apex Inner Circle Mastermind** offer featuring a boardroom coaching session visual with live 7-figure analytics monitor. Supports "Accept Offer" and "No Thanks" decisions. |
| **4** | **Confirmation Page** | Dynamically generated order receipt reflecting selected bumps and upsell choices with customer details, order timestamp, and customer center access links. |
| **5** | **Membership Hub** | **ClickFunnels 2.0 Customer Center:**<br>• *Level 1*: Downloadable PDF guides, swipe files, spreadsheets.<br>• *Level 2*: Audio masterclasses with interactive simulated web audio player + **"Simulate VIP Unlock"** toggle button. |
| **6** | **Booking Calendar** | Interactive month calendar, selectable dates, US Eastern time slots, intake form, and live confirmed appointment card. |
| **7** | **Email Automations** | 4 complete marketing sequences (Welcome, Cart Abandonment, Upsell Follow-up, Appointment Reminders). Clickable nodes opening **full editable copy drawers**. |
| **8** | **Technical Setup** | Technical checklist for Meta Pixel, Meta CAPI, Stripe Checkout, SPF, DKIM, and DMARC with copyable DNS snippets and diagnostic test triggers. |
